# Reference Data Catalog (QDF Assignment)

A scoping catalog of external gender- and queer-data sources, compiled as a reference for the collaborative. **Not a raw dataset itself**, and not listed in `data-ecosystem/knowledge_graph/data_registry.csv` — this is a pointer document to other organizations' data portals and reports, not data collected or extracted by this project.

## Contents

**`copy_of_saesha_qdf_assignment.xlsx`**

- `Datasets` — ~1000-row catalog of external datasets on gender and queer data, one row per source. Columns: `Type of Dataset` (e.g. Gender Data, Queer Data), `Organisation`, `Dataset`, `Features`, `Coverage`, `Granularity`, `Year/Frequency`, `Link`. Includes entries such as the World Bank Gender Data Portal, NFHS, World Values Survey, ILGA World Database, data.gov.in transgender-persons datasets, NACO surveillance reports, and corporate LGBT+ inclusion surveys.
- `Articles` — a short list of linked news articles relevant to gender/queer data in India.

## Usage note

Treat this as a lead-generation / desk-research reference for identifying new sources to onboard, not as an analysis-ready dataset. Links should be re-verified before use, as portal URLs and content can change over time.
